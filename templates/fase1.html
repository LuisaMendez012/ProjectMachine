01

Project Objective

Build a machine learning model to predict the occupancy level of public bike parking in Bogota using open mobility and weather data.

The goal is to optimize infrastructure use and support better decision-making for both citizens and public agencies.

02

Problem Context

Bogota has experienced a strong increase in bicycle use, which raises demand for parking spaces. Occupancy changes by time, location, and weather conditions.

Understanding these patterns helps improve urban planning and service delivery.

03

Business Questions

Which hours have the highest occupancy?
How does weather affect bike parking use?
Which zones have the highest demand?
Can future occupancy be predicted?

Project Viability

The project is viable thanks to available open data and technology, though there are some limitations to consider:

Incomplete data in some periods
Possible bias in data collection
User behavior can change after major events
07

Project Importance

This project applies data analysis and machine learning to solve mobility challenges and contribute to a more efficient and sustainable Bogota.
