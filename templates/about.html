About Smart Parking Prediction

Learn about the technology, methodology, and team behind this intelligent urban mobility solution.

Project Purpose

Smart Bicycle Parking Prediction is an innovative machine learning application designed to optimize urban mobility and bicycle parking infrastructure in Bogotá. The system uses advanced predictive analytics to estimate parking occupancy in real time, helping citizens make informed decisions about their bicycle commuting patterns.

This platform demonstrates how data science and artificial intelligence can be leveraged to address practical urban challenges, improve citizen experience, and support better decision-making for city planners and mobility services.

Context

Bogotá has experienced significant growth in bicycle use, creating demand for predictive parking information.

Solution

Real-time ML-powered predictions provide occupancy estimates for different zones and times.

Impact

Improved user experience, optimized infrastructure use, and data-driven urban planning.

Machine Learning Models

The system evaluates multiple algorithms to find the optimal balance between accuracy and interpretability.

Models Evaluated

Model Description Status
Random Forest Ensemble of decision trees with strong generalization capabilities. Best performer in cross-validation. Selected
Linear Regression Baseline linear model. Provides simple interpretable predictions for comparison. Baseline
K-Nearest Neighbors Instance-based learning. Captures local patterns in occupancy data. Evaluated
K-Means Clustering Unsupervised learning for occupancy pattern segmentation and anomaly detection. Exploratory

Selected Model: Random Forest Regression

  • R² Score: 0.87 (explains 87% of variance)
  • RMSE: 18.2 bicycles
  • MAE: 14.5 bicycles
  • Cross-validation fold consistency confirmed
