División del Dataset

04

Modelos Utilizados

Se evalúan cuatro algoritmos con diferentes niveles de complejidad y capacidad de generalización:

📈
Regresión Lineal — modelo base de referencia
🌿
Árbol de Decisión — interpretable y no lineal
🌲
Random Forest — conjunto de árboles con bagging
⚡
XGBoost — boosting con alta precisión
05

Entrenamiento del Modelo

Cada modelo se entrena con el conjunto de entrenamiento, ajustando sus hiperparámetros mediante validación cruzada para mejorar la generalización y reducir el sobreajuste.

06

Métricas de Evaluación

Se utilizan tres métricas estándar para comparar el desempeño de cada modelo de forma objetiva:

MAE Error Absoluto Medio — magnitud promedio del error
RMSE Raíz del Error Cuadrático Medio — penaliza errores grandes
R² Coeficiente de Determinación — varianza explicada
07

Resultados

0.87 R² Score

El modelo de Random Forest obtuvo el mejor desempeño con un R² de 0.87, indicando que explica el 87% de la varianza en la ocupación de los cicloparqueaderos. Supera a los demás algoritmos evaluados en todas las métricas.
