Fase 2: Ingeniería de Datos y Modelado

1. Preparación de los Datos

En esta fase se realizan procesos fundamentales para preparar los datos antes de aplicar el modelo:

  • Limpieza de datos (eliminación de errores y duplicados)
  • Manejo de valores nulos
  • Transformación de variables
  • Normalización de datos

2. Ingeniería de Características

Se crean nuevas variables para mejorar el modelo:

  • Hora del día
  • Día de la semana
  • Condiciones climáticas
  • Zona geográfica

3. Modelo de Machine Learning

Se implementa un modelo predictivo basado en una combinación lineal de variables, similar a una red neuronal simple.

El modelo calcula la ocupación utilizando pesos asociados a cada variable de entrada.

4. Variables del Modelo

  • Clima: Representa condiciones ambientales
  • Hora: Influye en la demanda
  • Zona: Representa ubicación

6. Evaluación del Modelo

El modelo puede evaluarse utilizando métricas como:

  • Error absoluto medio (MAE)
  • Raíz del error cuadrático medio (RMSE)
  • Coeficiente de determinación (R²)

7. Interpretación

El modelo permite identificar cómo cada variable afecta la ocupación, facilitando la toma de decisiones basada en datos.

8. Despliegue

Este sistema se implementa como una aplicación web utilizando Flask, permitiendo a los usuarios ingresar datos y obtener predicciones en tiempo real.
